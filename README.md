# 推甄審查室

台灣研究所推甄模擬審查儀表板。同一份申請檔，五種委員人格各自閱卷，再開招生委員會合議。

**線上試用：** [https://river-valley-zippy-timber.grok.me](https://river-valley-zippy-timber.grok.me)

> 這是模擬審查，不是真實錄取率預測。訊號與裁決皆為估算，不能代表任何學校的官方結果。

---

## 這是什麼

推甄書面審查很難「自己當委員」看一次。這個模擬器把常見審查人格做成可操作的儀表板：填材料、選委員、看評語依據、聽合議、再改材料重審。

沒有登入、沒有後端帳號。案件存在瀏覽器本機。

## 功能

- **申請檔**：學校、科系、GPA（4.3 / 4.0 / 百分制）、班排、英文（TOEIC / TOEFL / IELTS / GEPT 含版本）、專題、研究、論文、GitHub、實習、推薦信情況。
- **輸入驗證**：班排名須為正整數且不得大於人數；英文依考試種類與版本檢查區間。無效分數（例如 TOEIC 9999）會顯示「分數無效」，不會被當成優勢。
- **五種委員人格**：林（學業）、陳（研究潛力）、張（工程實作）、吳（英文與國際化）、黃（嚴格挑弱點）。權重公開，可調這所較看重的維度。
- **校名分級可改寫**：規則會把校名歸到 T0–T3，可檢視並覆寫。這是模擬假設，不是官方分級。
- **評語可追溯**：優勢／弱點標示「使用者提供」「規則推導」「資料不足」，並附觸發欄位與摘句。
- **合議裁決**：Strong Admit / Admit / Borderline / Waitlist / Reject。沒有假精確的錄取率百分比。
- **重審差異**：改材料再審後，顯示哪些委員改票、哪些風險消失、原因是什麼。
- **裁決之後**：試算補強、學業敏感度、多所對照、口試對打、材料改寫與時程。補強建議依剩餘時間、現有成果與成本排序——研究尚未成熟時，不會一律叫你趕論文。

## 怎麼用

1. 載入一份樣本（台大資工前段、逢甲實作、成大電機研究／英文缺），或直接填自己的材料。
2. 核對側欄訊號。無效欄位會標紅，且不能送審。
3. 選擇委員，必要時調整「本所較看重」。
4. 送交審查，點開卡片看評語依據與口試題。
5. 召開招生委員會，看合議紀錄與裁決。
6. 改材料後按「用目前材料再審」，對照「相對上次送審」。

| 層 | 選擇 |
| --- | --- |
| UI | React 19、TanStack Start、Tailwind CSS v4 |

| 審查 | 規則引擎（決定性，不呼叫 LLM） |

## 本機開發

需要 Node.js 22。

```bash
npm install
npm run dev
```

開發伺服器預設聽 `0.0.0.0:8080`。

```bash
npm run typecheck
npm run build
```
